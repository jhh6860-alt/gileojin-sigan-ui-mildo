# 길어진 시간의 밀도

제주 여행 속 두 번의 걷기에서 나타난 발견, 상호작용과 감정의 변화를 다루는 인터랙티브 정보디자인 웹사이트입니다.

## 실행
`index.html` 을 크롬으로 열면 됩니다. 설치할 것은 없습니다.
글꼴은 Google Fonts 에서 불러오므로 인터넷이 연결되어 있어야 의도한 글꼴로 보입니다.

## 현재 상태 (홈 완료)
- 홈: 커서 근처 반응, 스크롤로 사진 쌓기, 갈림길에서 사건 A·B 선택 — 동작함
- 개요·사건 A·사건 B·비교·연결·인사이트: 자리만 있음 (다음 단계에서 제작)

## 수정하는 곳
- 색: `css/style.css` 맨 위 `:root`
- 홈 사진 순서·라벨: `js/data.js` 맨 아래 `SITE_DATA.home`
- 홈 속도·간격·반응 범위: `js/home.js` 맨 위 '조절하기 쉬운 값들'
- 사진 교체: `assets/photos` 의 같은 이름 파일을 덮어쓰기

## Claude Code 에서 이어서 작업하기
1. 이 폴더를 원하는 위치에 압축 해제합니다.
2. 터미널에서 이 폴더로 이동한 뒤 `claude` 를 실행합니다.
3. Claude Code 가 `CLAUDE.md` 의 프로젝트 규칙과 현재 상태를 읽고 이어서 작업합니다.

변경 이력은 git 으로 관리됩니다. 첫 커밋이 '홈 완료' 상태의 보존본입니다.
